# Jannatul Hosna - Portfolio

Static portfolio site for Jannatul Hosna, a Computer Science and Engineering student and data management professional.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. The site has no build step or dependency installation.

## Deploy

Push the repository to `JannatulHosna.github.io` and enable GitHub Pages from the `main` branch root. To enable the CV download link, add the file `assets/Jannatul-Hosna-CV.pdf`.

The hero frame uses a professional initials treatment and does not include a personal photograph.
